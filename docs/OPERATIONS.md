# دليل العمليات والتشغيل (Operations Guide)

هذا الدليل يوضح إجراءات التشغيل والصيانة اليومية لنظام بوت في بيئة الإنتاج والتطوير.

## 1. قاعدة البيانات (SQLite)

- الموقع الافتراضي: `./data/bot.db`
- النمط: WAL (Write-Ahead Logging) لتحقيق أداء عالي وتزامن موثوق.
- الإعدادات المفعلة تلقائيًا:
  - `foreign_keys = ON`
  - `busy_timeout = 5000`
- الترحيلات:
  - تحفظ ملفات الترحيل في مجلد `drizzle/`.
  - لتطبيق أي ترحيلات جديدة:
    ```bash
    npm run db:migrate
    ```

> تنبيه: النسخ الاحتياطي التلقائي للبيانات مجدول للمراحل القادمة. في المرحلة الحالية، يوصى بأخذ نسخة من ملف `data/bot.db` قبل تطبيق أي تحديثات كبرى.

## 2. السجلات (Logging)

- الموقع الافتراضي: `./logs/`
- المحرك: Pino مدمج مع التدوير اليومي `pino-roll`.
- التنسيق: JSON منظم مع معرّف الخطأ ومصدر الحدث.
- التنقيح التلقائي: يتم حجب الكلمات الحساسة تلقائيًا مثل التوكنات ومفاتيح التشفير وكلمات المرور من أي سجل قبل كتابته.

## 3. إيقاف التشغيل الهادئ (Graceful Shutdown)

- يستمع البوت لإشارات `SIGINT` و`SIGTERM`.
- عند استلام إشارة الإيقاف:
  1. يتم تسجيل رسالة بدء الإيقاف.
  2. يتم قطع الاتصال ببوابة ديسكورد وإلغاء الاستماع للأحداث.
  3. يتم إغلاق اتصال قاعدة البيانات SQLite بشكل سليم لتفادي تلف ملفات WAL.
  4. تخرج العملية بكود 0.

## 4. خطوات التحديث والنشر

1. جلب التحديثات البرمجية من Git.
2. تثبيت التبعيات الجديدة: `npm ci` أو `npm install`.
3. فحص الجودة الشامل: `npm run check`.
4. تطبيق ترحيلات قاعدة البيانات: `npm run db:migrate`.
5. تحديث أوامر التطبيق إذا طرأ تغيير: `npm run register`.
6. بناء المشروع: `npm run build`.
7. إعادة تشغيل العملية: `npm start` أو عبر مدير عمليات مثل PM2 أو Systemd.
