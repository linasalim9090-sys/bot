# Phase 0 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** بناء نواة بوت ديسكورد تعمل فعليًا على سيرفر واحد: إعدادات صارمة، سجلات آمنة، SQLite مع ترحيلات، نظام أوامر وأحداث، i18n عربي بلا إيموجي، وأوامر `/ping`, `/help`, `/doctor`, `/settings`, `/module`.

**Architecture:** Monolith معياري في عملية Node واحدة. كل أمر يمر عبر سلسلة حراس مركزية ثم خدمة ثم مستودع بيانات. كل نص للمستخدم يأتي من i18n. كل عملية حساسة تُسجّل في `audit_log`. لا اتصال بـ Lavalink أو لوحة تحكم في هذه المرحلة.

**Tech Stack:** Node.js 22 LTS, TypeScript 5 strict, discord.js 14.27, SQLite + better-sqlite3 + Drizzle ORM, Zod, Pino, Vitest, ESLint, Prettier.

**Spec:** `docs/superpowers/specs/2026-10-22-discord-bot-design.md`

## Global Constraints

- سيرفر واحد فقط. `GUILD_ID` إلزامي، وأي أمر من سيرفر آخر يُرفض.
- Node.js 22 LTS أو أحدث. TypeScript strict مع `noUncheckedIndexedAccess`.
- Discord.js 14.27. استخدم حدث `clientReady` لا `ready`.
- SQLite بوضع WAL، `foreign_keys = ON`، `busy_timeout = 5000`.
- لا Redis، لا PostgreSQL، لا Lavalink، لا لوحة تحكم في هذه المرحلة.
- العربية هي اللغة الافتراضية، والإنجليزية احتياطية. أسماء الأوامر بالإنجليزية.
- لا إيموجي في أي نص يكتبه البوت. فحص آلي يفشل البناء عند وجود إيموجي.
- كل نص يظهر للمستخدم يمر عبر `t()` من i18n. لا نصوص عربية مكتوبة داخل الأوامر.
- الأمر الذي يعلن `defer` يستخدم `interaction.editReply` بعد التأجيل، لا `reply`.
- `GUILD_ID` و`OWNER_ID` و`CLIENT_ID` أرقام Snowflake من 17 إلى 20 رقمًا.
- التوكن لا يُطبع ولا يُسجّل ولا يُحفظ في git. `.env` مستثنى.
- كل مهمة تنتهي ببوابة التحقق المتاحة وcommit مستقل: `npm run typecheck && npm run lint && npm test` قبل Task 5، ثم `npm run check` بعد إضافة فحوص i18n والإيموجي.
- لا اختبار يتصل بديسكورد الحقيقي. استخدم واجهات وهمية.
- سقف الأوامر العلوية أقل من 90. هذه المرحلة تسجّل 5 أوامر فقط.
- المسارات: قاعدة البيانات `./data/bot.db`، السجلات `./logs`، النسخ لاحقًا في `backups/`.

```ts
import { z } from 'zod';
import { EnvError } from './errors.js';

const snowflake = z.string().regex(/^\d{17,20}$/, 'must be a Discord snowflake');

const envSchema = z.object({
  DISCORD_TOKEN: z.string().min(50),
  CLIENT_ID: snowflake,
  GUILD_ID: snowflake,
  OWNER_ID: snowflake,
  NODE_ENV: z.enum(['development', 'test', 'production']).default('development'),
  LOG_LEVEL: z.enum(['fatal', 'error', 'warn', 'info', 'debug', 'trace', 'silent']).default('info'),
  DATABASE_PATH: z.string().min(1).default('./data/bot.db'),
  LOG_DIR: z.string().min(1).default('./logs'),
  DEFAULT_LOCALE: z.enum(['ar', 'en']).default('ar'),
  DRY_RUN: z.enum(['true', 'false']).default('false').transform((value) => value === 'true'),
});

export type Env = z.infer<typeof envSchema>;

export function loadEnv(source: NodeJS.ProcessEnv = process.env): Env {
  const result = envSchema.safeParse(source);
  if (!result.success) {
    const issues = result.error.issues.map((issue) => `${issue.path.join('.')}: ${issue.message}`);
    throw new EnvError(issues);
  }
  return result.data;
}
```

```ts
import path from 'node:path';
import pino from 'pino';
import type { Env } from './env.js';

export type Logger = pino.Logger;

const redact = {
  paths: [
    'token',
    'DISCORD_TOKEN',
    'authorization',
    'cookie',
    'password',
    'secret',
    '*.token',
    '*.authorization',
    '*.cookie',
    '*.password',
    '*.secret',
  ],
  censor: '[Redacted]',
};

export function createLogger(env: Env, destination?: pino.DestinationStream): Logger {
  if (destination) {
    return pino({ level: env.LOG_LEVEL, redact }, destination);
  }

  if (env.NODE_ENV === 'production') {
    const transport = pino.transport({
      target: 'pino-roll',
      options: {
        file: path.join(env.LOG_DIR, 'bot'),
        frequency: 'daily',
        mkdir: true,
        size: '10m',
      },
    });
    return pino({ level: env.LOG_LEVEL, redact }, transport);
  }

  return pino({ level: env.LOG_LEVEL, redact });
}
```

Create `src/db/client.ts`:

```ts
import { mkdirSync } from 'node:fs';
import path from 'node:path';
import Database from 'better-sqlite3';
import { drizzle, type BetterSQLite3Database } from 'drizzle-orm/better-sqlite3';
import * as schema from './schema.js';

export type Db = BetterSQLite3Database<typeof schema>;

export function createDb(databasePath: string): {
  sqlite: Database.Database;
  db: Db;
} {
  if (databasePath !== ':memory:') {
    mkdirSync(path.dirname(databasePath), { recursive: true });
  }
  const sqlite = new Database(databasePath);
  sqlite.pragma('journal_mode = WAL');
  sqlite.pragma('foreign_keys = ON');
  sqlite.pragma('busy_timeout = 5000');
  const db = drizzle(sqlite, { schema });
  return { sqlite, db };
}

export function closeDb(sqlite: Database.Database): void {
  sqlite.close();
}
```

Create `src/i18n/index.ts`:

```ts
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { assertNoEmoji } from '../ui/emoji.js';

export type Locale = 'ar' | 'en';
export type Messages = Record<string, string>;
export type Translator = (key: string, vars?: Record<string, string | number>) => string;

let cached: Record<Locale, Messages> | undefined;

export function loadLocales(): Record<Locale, Messages> {
  if (cached) return cached;
  const read = (locale: Locale): Messages =>
    JSON.parse(readFileSync(fileURLToPath(new URL(`./${locale}.json`, import.meta.url)), 'utf8')) as Messages;
  cached = { ar: read('ar'), en: read('en') };
  return cached;
}

export function flattenKeys(value: unknown, prefix = ''): string[] {
  if (typeof value !== 'object' || value === null) return prefix ? [prefix] : [];
  return Object.entries(value).flatMap(([key, child]) =>
    flattenKeys(child, prefix ? `${prefix}.${key}` : key),
  );
}

export function createTranslator(locale: Locale): Translator {
  const locales = loadLocales();
  const primary = locales[locale] ?? locales.ar;
  const fallback = locales.en;
  return (key, vars) => {
    const template = primary[key] ?? fallback[key] ?? key;
    if (process.env.NODE_ENV !== 'production') assertNoEmoji(template);
    return template.replace(/\{(\w+)\}/g, (_match, name: string) =>
      vars && name in vars ? String(vars[name]) : `{${name}}`,
    );
  };
}
```

For this plan I recommend **subagent-driven execution**, because the foundation interfaces are load-bearing: a mistake in the DB schema, guard order, or settings versioning propagates into every later module, and a fresh reviewer per task is cheaper than rebuilding the base later.

The two options:
